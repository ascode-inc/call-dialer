# call-dialer

株式会社ASCODEの営業が、iPhoneのGoogleスプレッドシート（架電リスト）から電話をかけるためのページです。

## なぜあるか

iPhoneのスプレッドシートアプリは `tel:` のリンクを開けません。そこで、電話番号のリンク先をこのページにして、
「会社名・番号・発信ボタン」だけを表示し、ボタンから発信します。

## 何をしているか / していないか

- 表示するのは、URLの `#` より後ろで渡された会社名と番号だけです（例: `#n=0312345678&c=株式会社サンプル`）
- `#` より後ろはサーバーに送られない部分なので、番号や会社名はGitHubにも記録されません
- データの保存・送信・アクセス解析は一切していません。HTML 1枚と robots.txt だけです
- 検索エンジンには載せない設定です（`noindex` と robots.txt）
